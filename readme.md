# 📖 About This Repository

This repository documents my **100 Days System Administrator Challenge**, where I learn and practice real-world System Administration skills through daily hands-on labs, documentation, and projects.

The goal is not just to complete tutorials but to build practical experience similar to what a Junior System Administrator performs in enterprise environments.

Every day includes:

- 📚 Theory Notes
- 💻 Practical Labs
- 📸 Screenshots
- 📝 Documentation
- ✅ Learning Outcomes

This repository serves as both my learning journal and professional portfolio.

---

# 🎯 Objectives

By the end of this challenge, I aim to:

- Master Linux Administration
- Learn Windows Server Administration
- Configure Active Directory
- Manage DNS & DHCP Servers
- Understand Computer Networking
- Deploy Virtual Machines
- Learn VMware & Hyper-V
- Build Home Lab Infrastructure
- Learn Shell Scripting
- Automate Administrative Tasks
- Learn Docker Fundamentals
- Deploy Servers to AWS
- Gain real-world troubleshooting experience
- Prepare for System Administrator certifications
