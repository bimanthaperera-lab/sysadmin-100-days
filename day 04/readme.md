# 👤 Day 04 - Linux User & Group Management

## 📖 Overview

On Day 04, I practiced Linux user and group management. I created new users and groups, assigned users to groups, granted administrative privileges, switched between user accounts, and explored important Linux account configuration files.

These tasks are part of the daily responsibilities of a Linux System Administrator.

---

## 🎯 Objectives

- Create Linux users
- Create groups
- Assign users to groups
- Grant sudo privileges
- Switch between users
- Lock and unlock user accounts
- Change passwords
- Delete users
- Explore system account files

---

## 🛠 Skills Practiced

- Privilege Management
