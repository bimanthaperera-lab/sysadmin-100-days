# 📂 Day 02 - Linux File System & File Management

## 📖 Overview

On Day 02, I explored the Linux file system and practiced essential file and directory management operations. This session focused on navigating the Linux directory structure, creating and managing files and folders, editing text files, and organizing data using common Linux commands.

Understanding the Linux file system is a fundamental skill for every System Administrator, as daily administrative tasks heavily rely on efficient command-line file management.

---

## 🎯 Objectives

- Understand the Linux directory hierarchy
- Navigate between directories
- Create and manage directories
- Create, edit, copy, move, rename, and delete files
- Learn commonly used Linux file management commands
- Practice organizing files using the terminal
