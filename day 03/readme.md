# 👥 Day 03 - Linux Users, Groups & File Permissions

## 📖 Overview

On Day 03, I learned the fundamentals of Linux user management, group management, and file permissions. Understanding these concepts is essential for maintaining system security and controlling access to files and directories in a Linux environment.

This session focused on identifying users and groups, understanding ownership, interpreting Linux permission notation, and modifying file permissions using the `chmod` command.

---

## 🎯 Objectives

- Understand Linux users and groups
- Learn the purpose of the root user
- Understand the `sudo` command
- View user and group information
- Learn Linux file ownership
- Understand file permission notation
- Modify file permissions using `chmod`
